# Задание 3. HashSet

## Задача 3.3

### Текст задачи

Задан некоторый набор блюд в кафе. Определить для каждого из блюд, какие из них заказывали все посетители, какие — некоторые из посетителей, и какие не заказывал никто.

### Алгоритм решения

Используются встроенные методы HashSet (без циклов перебора):
1. **Заказывали все:** создается HashSet на основе первого заказа, затем в цикле вызывается `IntersectWith()` для каждого следующего заказа.
2. **Заказывали некоторые:** с помощью `UnionWith()` собираем все блюда, которые кто-либо заказывал, затем через `ExceptWith()` вычитаем тех, кто у всех.
3. **Не заказывал никто:** берем общий список блюд и вычитаем через `ExceptWith()` тех, кого кто-то заказывал.

### Тестирование

1)На скриншоте показан ввод данных с клавиатуры для анализа заказов в кафе. 

1. В меню было введено 3 блюда: `Пицца`, `Бургер`, `Картошка`.
2. Затем были введены заказы для 4 посетителей. У третьего посетителя `Бургер` был введен дважды, но благодаря использованию `HashSet`, дубликат был проигнорирован, и в заказе остался только один `Бургер`.

**Результаты:**
* **Заказывали все:** (пусто). Ни одно блюдо не было выбрано всеми четырьмя посетителями одновременно.
* **Заказывали некоторые:** `Картошка, Пицца, Бургер`. Эти блюда выбирали разные посетители.
* **Не заказывал никто:** (пусто). Все блюда из меню были кем-то заказаны.
