# Задание 1. List

## Задача 1.3

### Текст задачи

Даны упорядоченные списки L1 и L2. Вставить элементы списка L2 в список L1, не нарушая его упорядоченности.

### Алгоритм решения

1. Создается копия списка L1 (чтобы не изменять исходные данные).
2. Создается копия списка L2, которая сортируется методом `.Sort()` (для защиты от неправильного ввода).
3. Проходим по каждому элементу L2. Внутренним циклом ищем в L1 первый элемент, который больше текущего. Вставляем перед ним через `.Insert()`.
4. Если не нашли больше — добавляем в конец через `.Add()`.

### Тестирование


На скриншоте продемонстрирован ввод двух упорядоченных списков. 
В список `L1` были введены числа от 1 до 6, а в список `L2` — числа от 2 до 567. 
Программа корректно объединила списки, сохранив общий порядок возрастания. Двойка из списка `L2` встала на правильное место рядом с двойкой из `L1`, и весь итоговый список отсортирован без нарушений.

# Задание 3. HashSet

## Задача 3.3

### Текст задачи

Задан некоторый набор блюд в кафе. Определить для каждого из блюд, какие из них заказывали все посетители, какие — некоторые из посетителей, и какие не заказывал никто.

### Алгоритм решения

Используются встроенные методы HashSet (без циклов перебора):
1. **Заказывали все:** создается HashSet на основе первого заказа, затем в цикле вызывается `IntersectWith()` для каждого следующего заказа.
2. **Заказывали некоторые:** с помощью `UnionWith()` собираем все блюда, которые кто-либо заказывал, затем через `ExceptWith()` вычитаем тех, кто у всех.
3. **Не заказывал никто:** берем общий список блюд и вычитаем через `ExceptWith()` тех, кого кто-то заказывал.
